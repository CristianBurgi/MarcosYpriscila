# Módulo Feature: Event

Este paquete contiene la lógica de negocio, controladores, servicios y entidades relacionadas con la gestión del evento :
- Configuración del evento (slug, fecha, límite post-evento de 15 días).
- Configuración de límites globales (máximo 1000 fotos, tamaño máximo de 10MB por archivo).
- DTOs de respuesta e información general del evento.
