# Módulo Feature: Event

Este paquete contiene la lógica de negocio, controladores, servicios y entidades relacionadas con la gestión del evento (Boda de Marcos y Priscila):
- Configuración del evento (`marcos-y-priscila`, fecha 19/9/2026, límite post-evento de 15 días).
- Configuración de límites globales (máximo 1000 fotos, tamaño máximo de 10MB por archivo).
- DTOs de respuesta e información general del evento.
