# Fuentes del PDF

Instancias estáticas generadas con `fontTools.varLib.instancer` a partir de las fuentes
variables de [google/fonts](https://github.com/google/fonts) (PDFBox no selecciona pesos
de una fuente variable: usaría siempre el peso por defecto).

| Archivo | Origen | Eje fijado |
|---|---|---|
| PlayfairDisplay-Regular / SemiBold | `ofl/playfairdisplay/PlayfairDisplay[wght].ttf` | wght 400 / 600 |
| PlayfairDisplay-Italic | `ofl/playfairdisplay/PlayfairDisplay-Italic[wght].ttf` | wght 400 |
| CormorantGaramond-Medium / Bold | `ofl/cormorantgaramond/CormorantGaramond[wght].ttf` | wght 500 / 700 |
| CormorantGaramond-MediumItalic | `ofl/cormorantgaramond/CormorantGaramond-Italic[wght].ttf` | wght 500 |
| NotoSerif-Regular | `ofl/notoserif/NotoSerif[wdth,wght].ttf` | wght 400, wdth 100 |
| NotoEmoji-Regular (monocromática) | `ofl/notoemoji/NotoEmoji[wght].ttf` | wght 400 |

Todas bajo SIL Open Font License 1.1 (ver los `*-OFL.txt` de esta carpeta).
